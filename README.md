# Ecosystem Simulation (C++) POO

## Description

This project simulates an ecosystem where different animal species interact in a shared environment.

The simulation models the behavior of wolves, sheep, and foxes using object-oriented programming concepts.

Developed as part of a university C++ programming project.

---

## Features

- Ecosystem simulation
- Multiple animal species
- Dynamic interactions between animals
- Modular C++ architecture

---

## Technologies

- C++
- Object-Oriented Programming

---

## Project Structure

- `Animal.*`
- `Loup.*`
- `Mouton.*`
- `Renard.*`
- `Univers.*`
- `Case.*`
- `main.cpp`

---

## Build

Compile with any C++17 compatible compiler.

Example:

```bash
g++ *.cpp -o ecosystem
./ecosystem
```
